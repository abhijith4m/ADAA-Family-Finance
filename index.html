Backup & Data Protection

Protect your family finance data. Download a full JSON backup before major changes or when switching devices.

Backup includes transactions, budgets, recurring bills, EMIs, goals, opening balances and accounts.
Recommended: Keep copies in at least two places, such as your phone/computer and Google Drive. A backup file is not automatically synced to the cloud.

Cloud Sync & Family Access

Connect your ADAA workspace to Supabase to share the same household data across signed-in devices. GitHub Pages remains the website host; Supabase stores and protects the data.

Offline / local browser mode

To enable cloud sync, configure supabase-config.js and run supabase/schema.sql in your Supabase project.

Cloud data is isolated by household using Row Level Security. Admin members can manage all ADAA data. Entry members can add transactions; the database prevents them from replacing or editing existing records or admin settings. Keep JSON backups as an independent recovery option.

Security & Access Control

Change the Admin and Entry User PINs and set an inactivity lock. These controls are browser-only.

Default PINs are 1234 (Admin) and 5678 (Entry User) until changed.
